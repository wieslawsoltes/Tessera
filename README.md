# Tessera

**Your command line, composed.**

Native cross-platform terminal workspace built with C#, Avalonia and RoyalTerminal.

The implementation follows the Tessera Obsidian, Porcelain and Blueprint design package: workspace navigation, independent tab groups, nested docking, command menus, reusable commands, profiles and terminal tools.

This repository is being initialized with the native implementation and automated validation. The browser design is a visual reference, not a substitute for the native terminal runtime.
